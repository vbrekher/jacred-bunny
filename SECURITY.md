# Security policy

JacRed Bunny is a development preview. It has not completed production security acceptance.

Never publish Bunny account keys, SQL tokens, Storage passwords, tracker cookies, passkeys, private catalogs or backup dumps in issues, CI logs or screenshots. Use distinct search and administration keys. Keep SQL write credentials out of Edge and browser code.

Report suspected vulnerabilities privately through the repository's GitHub private vulnerability reporting feature if available. If it is unavailable, contact the repository owner through an existing private channel; do not post exploit credentials publicly. There is no guaranteed response SLA.

Network operators must provide the corresponding modified source under AGPL-3.0. Use only sources and content you are authorized to access. Do not bypass tracker access controls, CAPTCHA or rate limits.
